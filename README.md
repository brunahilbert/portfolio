# Bruna Hilbert — Portfolio Website

This repository contains the source code for my personal portfolio website, created to showcase my work, experience, skills, and projects as a Web Developer.

The portfolio reflects my transition from **Visual Arts teaching to Web Development**, combining my background in visual communication and design with my technical experience in frontend and full-stack development.

🌐 **Live website:**  [brunahilbert.github.io/portfolio](https://brunahilbert.github.io/portfolio/)


## About the Project

The goal of this project is to create a personal website that presents my professional profile, selected client work, technical projects, and contact information in a clear and visually engaging way.

Unlike my previous portfolio, this version focuses not only on projects from my Full-Stack Web Development studies, but also on **real client work and technologies I have worked with professionally**.

The website was designed and developed from scratch using HTML, CSS, and JavaScript, with a strong focus on responsive design, visual identity, usability, and clean presentation.


## Features

-   Responsive single-page portfolio website
-   About section with my background and professional profile
-   Technology and skills overview
-   Selected client work
-   Personal and educational projects
-   Project links to GitHub repositories and live demos
-   Dedicated case studies for selected projects
-   Downloadable CV
-   Contact section with email, GitHub, and LinkedIn
-   Custom visual design and animations
-   Responsive layout for different screen sizes
-   GitHub Pages deployment


## Deployment

The portfolio is deployed using **GitHub Pages**.

The website is served from the `main` branch, using the repository root as the publishing directory.

Every update pushed to the repository can be reflected on the live website through GitHub Pages.
